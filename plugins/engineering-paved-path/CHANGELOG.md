# Changelog

## 1.0.0 — 2026-10-15

Initial release.

First-party:

- `onion-architecture` — backend ring model with a placement guide, rules for
  HTTP handlers, persistence, contracts, vendor SDKs and dependency injection,
  enforcement options per ecosystem, a known-exceptions format, worked
  examples, and a table of 27 stable rule identifiers.
- `frontend-architecture` — React placement ladder with rules for components,
  constants, helpers, styling, copy, state, hooks, data, contracts, the
  server/client seam, imports and testing; compliance greps in
  `enforcement.md`; worked examples; and a table of 39 stable rule
  identifiers.
